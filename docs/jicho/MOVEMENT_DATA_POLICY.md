# Movement and travel data policy

## Purpose

Travel and asset movement can be relevant evidence in:
- sanctions evasion,
- procurement influence,
- lobbying,
- covert ownership/control,
- asset recovery,
- state-business relationships.

But movement data can also create physical-safety and harassment risks.

## Default rule

**Record history, not live pursuit.**

The public product must not become a real-time person-tracking service.

## Allowed public uses

Where there is a documented public-interest nexus:
- official travel already publicly announced,
- historical/delayed aircraft or vessel movements from lawful public sources,
- asset ownership/registration history,
- public conference/event appearances,
- documented border/jurisdiction presence,
- movement relevant to a published evidence chain.

## Safeguards

Default public delay:
- at least 72 hours for transport movements,
- longer where safety risk is elevated.

Prefer:
- city/airport/port level,
- route/history,
- entity/asset movement,
over:
- exact current coordinates,
- hotel/location within a city,
- private residence,
- family-member movements.

Never publish:
- a “notify me when this person is near me” feature,
- private home addresses,
- real-time precise location of a person,
- movement of children/family members without overwhelming public-interest justification,
- evasion instructions for privacy/safety controls.

## U.S. aviation context

FAA recognizes real-time ADS-B privacy concerns and operates:
- LADD (Limiting Aircraft Data Displayed)
- PIA (Privacy ICAO Address)

References:
https://www.faa.gov/pilots/ladd
https://www.faa.gov/air_traffic/technology/equipadsb/privacy

JICHO must not treat privacy mechanisms themselves as evidence of wrongdoing.

## Evidence state

Travel coincidence is not causality.

A movement event must be stored as:
```
asset/person/entity → observed presence/movement → source → time → uncertainty
```

Any claim connecting travel to corrupt conduct requires independent causal evidence.

## Design

Movement should appear as one tab inside a dossier:
- Timeline
- Money
- Relationships
- Travel
- Assets
- Documents

It should never dominate the public homepage.
