# JICHO — Public Integrity Observatory (incubator)

**Status:** research-complete enough for implementation discovery; integrated architecture remains unvalidated until blind backtesting.

JICHO is a public-interest investigation and accountability-memory system. It is not a corruption score, blacklist, accusation engine, or substitute for journalists, auditors, investigators, prosecutors, or courts.

## Mission

Make public-interest facts harder to erase, public money easier to reconcile with real-world outcomes, hidden ownership harder to use as a jurisdictional reset, and false accusations harder to sustain.

Core pipeline:

```
SENSE → CONNECT → QUESTION → VERIFY → ROUTE → PUBLISH/REFER → OUTCOME → MEMORY → ADAPT
```

Reasoning doctrine:

```
FRAME → UNIVERSE → BLIND SPOT → VIEWPOINT → PROVENANCE
→ RIVALS → CAUSALITY → INVERSION → TRANSFER → STOP
```

Meta-question:

> What am I not even asking—and what would my present way of looking make impossible to see?

## Immutable rules

1. Anomaly ≠ wrongdoing.
2. AI output ≠ evidence.
3. Relationship ≠ causality.
4. Repeated reporting ≠ independent confirmation.
5. Legal ownership ≠ operational control ≠ economic benefit.
6. “No evidence found” ≠ evidence of absence without a coverage audit.
7. Every leading hypothesis gets a competing and null model.
8. Every material claim retains source-level provenance.
9. Every case preserves exculpatory evidence, corrections, reversals and acquittals.
10. Political victory, dismissal, rebranding, jurisdiction change and time do not erase historical state.
11. Sensitive source identity is compartmentalized from the public evidence graph.
12. Publication/referral thresholds are human decisions.

## Design goal

JICHO should make the *next investigation cheaper* without making accusation cheaper.
