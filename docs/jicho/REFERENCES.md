# Reference systems and research anchors

Use these as precedent, not as unquestioned templates.

- Open Contracting Partnership — procurement red flags and OCDS
  https://www.open-contracting.org/
- OCCRP Aleph / FollowTheMoney — investigative entity and document graphs
  https://aleph.occrp.org/
  https://followthemoney.tech/
- ICIJ Datashare — secure/self-hosted investigative document analysis
  https://datashare.icij.org/
- OpenSanctions — entity resolution and provenance-aware data
  https://www.opensanctions.org/
- World Bank StAR — beneficial ownership / asset recovery
  https://star.worldbank.org/
- FATF — beneficial ownership standards and multi-source verification
  https://www.fatf-gafi.org/
- GIJN — cross-border investigative collaboration and security
  https://gijn.org/
- Kenya PPRA / procurement systems
  https://ppra.go.ke/
- Office of the Auditor-General Kenya
  https://www.oagkenya.go.ke/
- Kenya Law
  https://new.kenyalaw.org/

Research principles to preserve:
- random + risk-based auditing
- false-positive/benign controls
- due process as system integrity
- cross-border portability
- institutional redundancy
- append-only accountability memory
- scheme topology over permanent person labels
